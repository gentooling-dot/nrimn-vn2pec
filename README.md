# Zender

Privé IPTV-speler voor de telefoon. Eén HTML-pagina, geen backend.

- Laadt M3U-playlists (standaard [iptv-org/iptv](https://github.com/iptv-org/iptv), België)
- Zoeken, filter op categorie, favorieten (lokaal opgeslagen)
- HLS via hls.js, native afspelen op iOS
- Eigen M3U-link mogelijk via **Bron**
- Installeerbaar als app: open in browser → *Zet op beginscherm*

Lokaal testen: `python3 -m http.server` en open http://localhost:8000
